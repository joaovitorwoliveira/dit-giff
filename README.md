# Dit Giff

A native macOS app for reading the full diff between a branch and its base before
opening the merge request.

## Requirements

- macOS with Xcode installed (Mac App Store, free). Nothing else — no package
  manager, no API key.
- First launch of Xcode asks for the license and extra components. Only the macOS
  platform is needed.

## Layout

```
DitGiff/              The app. Open DitGiff.xcodeproj from here.
docs/product/         Product, design system and Swift setup docs.
docs/design-handoff/  HTML prototypes and screen spec.
ds-bundle/            Design tokens, generated by design-sync.
assets/icon/          App icon, drawn in code.
```

## Run

Open `DitGiff/DitGiff.xcodeproj` in Xcode and press `Cmd+R`.

## Build and test from the command line

```sh
# build
xcodebuild -project DitGiff/DitGiff.xcodeproj -scheme DitGiff -configuration Debug build

# test
xcodebuild -project DitGiff/DitGiff.xcodeproj -scheme DitGiff test
```

## Regenerate the app icon

The PNGs are build artifacts. Edit the constants at the top of `render-icon.swift`,
then rebuild and copy the icon set into the app's asset catalog:

```sh
./assets/icon/build.sh
cp assets/icon/AppIcon.appiconset/* DitGiff/DitGiff/Assets.xcassets/AppIcon.appiconset/
```

## Sync design tokens

`ds-bundle/` is generated — never edit it by hand. Change a value in
`docs/product/DESIGN-SYSTEM.md`, then run the Claude Design sync configured in
`.design-sync/config.json`.
